Um Stadtränge, Boni und Luftalarm-Meldungen direkt zu erhalten, folge diesen 2 Schritten:

Schritt 1

Code im Spiel generieren

Verbinde dich mit dem Server und gib im Chat folgenden Befehl ein:
/discord link

Schritt 2

Code an den Bot senden

Sende den erhaltenen Code als Direktnachricht (PN) an unseren Discord-Bot:
@Homeland Survival#5789

Kannst du dem Bot keine Nachricht senden?
Überprüfe deine Discord-Einstellungen: Benutzereinstellungen ➔ Privatsphäre & Sicherheit ➔ Direktnachrichten von Servermitgliedern erlauben aktivieren und den Code erneut absenden.
